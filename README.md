# Usual Labs Homebrew tap

Homebrew casks for [Usual Labs](https://github.com/usual-labs) apps.

```bash
brew install --cask usual-labs/tap/usual-bot
```

| Cask | App |
| --- | --- |
| `usual-bot` | [Usual Bot](https://github.com/usual-labs/usual-bot), a native messenger for your Hermes Bots. Needs macOS 15 or later. |

Update with `brew upgrade --cask usual-bot`. The cask installs the signed, notarized download from
the app's [latest release](https://github.com/usual-labs/usual-bot/releases/latest).
